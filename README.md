# 주안초 나이스 시간표 자동 입력시스템

구글 시트의 주간 시간표를 나이스 [학급담임 > 교육과정 > 시간표관리 > 학급시간표관리]에 자동으로 입력합니다.
* **프로그램 개발자 : 교사 백천재**

## 선생님용 설치 방법 (처음 한 번만, 약 3분)

**1. Tampermonkey 설치**
크롬 웹스토어에서 "Tampermonkey"를 검색해 [Chrome에 추가]를 누릅니다.

**2. 사용자 스크립트 허용 켜기**
주소창에 `chrome://extensions` 를 입력 → Tampermonkey의 [세부정보] → **"사용자 스크립트 허용"** 스위치를 켭니다.
(스위치가 없으면 화면 오른쪽 위 [개발자 모드]를 켜 보세요. Edge는 `edge://extensions` 에서 같은 방법입니다.)

**3. 프로그램 설치 (링크 클릭)**
아래 링크를 누르면 Tampermonkey 설치 화면이 뜹니다. [설치]를 누르세요.

👉 https://raw.githubusercontent.com/KirmaBeatles/neis-timetable/main/juan5-timetable.user.js

**4. 처음 설정**
나이스에 로그인하면 화면 오른쪽에 "주안초 나이스 시간표 자동 입력시스템" 창이 나타납니다.
1. 담임 선생님 이름과 반을 입력합니다.
2. 전담 과목명(예: 도덕, 과학, 영어, 체육(보건) 등)과 전담 선생님 성함을 입력합니다.
3. **[+ 전담 과목 추가하기]** 버튼을 눌러 우리 반의 전담 과목과 선생님 성함을 필요한 만큼 모두 추가합니다. (잘못 추가한 줄은 옆의 **[-]** 버튼으로 지울 수 있습니다.)
4. 모두 입력했으면 **[설치 완료]**를 누릅니다.
*(※ 전담 선생님 성함은 나이스 우클릭 메뉴에 나오는 이름과 같아야 합니다. 예: 김미애)*

## 사용 방법
1. 위쪽 드롭다운에서 주차를 선택하면 시트의 시간표가 표시됩니다.
2. **[나이스 입력]**을 누르면 나이스에서 자동으로 메뉴 이동 → 주차 선택 → 칸 입력 → [저장] → "저장하시겠습니까?" [확인] → "저장되었습니다" 알림 [확인]까지 진행합니다.
3. 입력 중에는 마우스와 키보드를 건드리지 마세요. **[중지]** 버튼으로 멈출 수 있습니다.
4. "저장은 내가 직접 누르기"를 체크하면 저장 직전에 멈춥니다. 처음에는 체크하고 확인해 보세요. (이때는 [저장]과 이어지는 [확인] 두 번을 모두 직접 누릅니다.)
5. 저장 완료 알림까지 확인되면 로그에 **■ 완료**가 나옵니다. 알림을 확인하지 못하면 노란 글씨로 "저장이 끝났는지 확인하지 못했습니다"라고 알려 주니, 그때는 나이스 화면을 직접 확인해 주세요.

* **전담 과목·선생님 변경/추가/삭제**: 실행창에서도 **[변경]** 버튼을 눌러 과목명과 선생님 성함을 고칠 수 있으며, 옆의 **[-]** 버튼으로 전담 과목을 삭제하거나 **[+ 전담 과목 추가하기]** 버튼으로 새 전담 과목을 추가할 수 있습니다.
* 나이스 화면이 바뀌어 안 될 때는 창 아래 **[로그 복사]**로 복사해서 보내 주세요.

## 관리자용 (한 번만 하면 됩니다)

### A. 시트 읽기용 웹앱 배포
1. 시간표 시트 → 확장 프로그램 → Apps Script → `Code.gs` 내용 붙여 넣기
2. [배포] → [새 배포] → 유형 "웹 앱" → 실행 사용자 "나", 액세스 권한 "모든 사용자" → 배포
3. 나온 `https://script.google.com/macros/s/…/exec` 주소를 복사

### B. 스크립트에 주소 넣기
`juan5-timetable.user.js`의 아래 줄에 3번 주소를 넣으면, 다른 선생님은 주소를 입력할 필요가 없습니다.

```js
const DEFAULT_API_URL = 'https://script.google.com/macros/s/…/exec';
```

### C. 업데이트 배포
`juan5-timetable.user.js`를 고친 뒤에는 맨 위 `@version`과 `const VERSION`을 함께 올려서 GitHub에 올리면, 설치한 선생님들의 Tampermonkey가 자동으로 새 버전을 받습니다.
